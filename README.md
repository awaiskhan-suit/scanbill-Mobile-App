
# 📦 Barcode Product Scanner & Billing App

A mobile **Barcode Product Scanner and Billing Application** designed to simplify product management, barcode scanning, quantity control, and price calculation.

## 🏷️ Product Management

Before using the scanner, the user can add and save product information, including:

* Product Code Number
* Product Name
* Product Price

Once the product information is saved, it can be identified using its code number.

## 📷 Barcode Scanning

The application allows users to **scan the product code directly from the product**.

After scanning a registered product, the application automatically displays:

* Product Name
* Product Price
* Product Quantity

This eliminates the need to manually search for products during the billing process.

## ➕➖ Quantity Management

Users can increase or decrease the quantity of scanned products using **Add (+)** and **Remove (−)** buttons.

Whenever the quantity changes, the **corresponding total price is automatically updated**.

For example:

**Product Price:** 100
**Quantity:** 2
**Total:** 200

## 🛒 Multiple Product Scanning

The application supports scanning **multiple products in a single session**.

Users can continuously scan different products, and each scanned product is added to the current purchase list with its:

* Name
* Price
* Quantity
* Total Amount

The application automatically calculates the overall amount based on the selected products and their quantities.

## ⭐ Key Features

* 📦 Add Product Details
* 🔢 Product Code Management
* 📷 Barcode/Code Scanning
* 🔍 Automatic Product Identification
* 💰 Automatic Price Calculation
* ➕ Increase Quantity
* ➖ Decrease Quantity
* 🛒 Multiple Product Scanning
* 🧾 Automatic Purchase Total

## 🎯 Project Objective

The main objective of this application is to provide a **fast and convenient product scanning and billing solution**. Instead of manually entering product information during every purchase, users can scan product codes to instantly retrieve product details and calculate the total price.
